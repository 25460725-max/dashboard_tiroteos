# Dashboard de Análisis de Tiroteos Escolares en EE. UU.

Proyecto interactivo desarrollado en Python utilizando Streamlit, Pandas y Plotly a partir de los datos históricos de The Washington Post.

## Estructura del Proyecto
- app.py: Código fuente de la aplicación web de Streamlit.
- requirements.txt: Dependencias requeridas para la ejecución.
- README.md: Documentación e instrucciones.

## Instrucciones de Ejecución Local
1. Instalar las dependencias:
   pip install -r requirements.txt
2. Iniciar el dashboard:
   streamlit run app.py
